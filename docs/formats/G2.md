# Formato G2

El Formato G2 reporta ventas de potencia y energía.

## Fuente principal

```text
VEPOEN.DBF
```

## Catálogo local

```text
config/local/g2_distributors.yaml
```

## Flujo soportado

```text
crear plantilla VEPOEN
validar plantilla VEPOEN
exportar VEPOEN.DBF
validar fuentes G2
generar TXT G2
```

## Crear plantilla

```powershell
sisgen create-vepoen-template `
  --source data\raw\VEPOEN.DBF `
  --period 2025-12 `
  --catalog config\local\g2_distributors.yaml
```

## Validar plantilla

```powershell
sisgen validate-vepoen-template `
  reports\templates\VEPOEN_2025_12_template.xlsx `
  --period 2025-12 `
  --catalog config\local\g2_distributors.yaml `
  --fail-on-errors
```

## Exportar DBF

```powershell
sisgen export-vepoen-dbf `
  --source data\raw\VEPOEN.DBF `
  --template reports\templates\VEPOEN_2025_12_template.xlsx `
  --period 2025-12 `
  --catalog config\local\g2_distributors.yaml
```

## Validar fuentes

```powershell
sisgen validate-g2-sources `
  --vepoen reports\dbf\2025-12\VEPOEN.DBF `
  --period 2025-12 `
  --catalog config\local\g2_distributors.yaml `
  --fail-on-errors
```

## Generar TXT

```powershell
sisgen create-g2-txt `
  --vepoen reports\dbf\2025-12\VEPOEN.DBF `
  --period 2025-12 `
  --catalog config\local\g2_distributors.yaml
```
