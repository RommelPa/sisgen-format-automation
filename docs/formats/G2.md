# Formato G2 - Venta mensual de potencia y energía a distribuidoras

## Objetivo

El Formato G2 reporta la venta mensual de potencia y energía de EGASA a empresas distribuidoras.

El reporte se genera a partir del archivo `VEPOEN.DBF`.

## Fuente DBF usada

| Fuente | Uso |
|---|---|
| VEPOEN.DBF | Ventas de energía, potencia, demanda y facturación por distribuidora y barra |

## Campos principales

| Campo | Descripción |
|---|---|
| CANOREG | Año del registro |
| CMESREG | Mes del registro |
| CCODEMP | Código de empresa generadora |
| CCODDIS | Código de empresa distribuidora |
| CSIELDI | Campo auxiliar SISGEN |
| CCOSUES | Campo auxiliar SISGEN |
| CNOMBAR | Nombre de barra de entrega |
| CCLRELI | Tipo de cliente: regulado o libre |
| NTENBAR | Tensión de barra en kV |
| NPRPOBA | Precio de potencia en barra |
| NPRENHO | Precio de energía en horas punta |
| NPRENFU | Precio de energía en horas fuera de punta |
| NENVEHO | Energía vendida en horas punta |
| NENVEFU | Energía vendida en horas fuera de punta |
| NENVETO | Energía vendida total |
| NPOCOHO | Potencia contratada en horas punta |
| NPOCOFU | Potencia contratada en horas fuera de punta |
| NMADEHO | Máxima demanda en horas punta |
| NMADEFU | Máxima demanda en horas fuera de punta |
| NFACPOT | Facturación por potencia |
| NFACENE | Facturación por energía |

## Catálogo local

G2 usa un catálogo local para traducir `CCODDIS` a nombres visibles de distribuidoras.

Archivo local esperado:

```text
config/local/g2_distributors.yaml
```

### Flujo operativo
1. Colocar VEPOEN.DBF en data/raw.
2. Crear o actualizar config/local/g2_distributors.yaml.
3. Validar fuentes G2.
4. Generar TXT G2.
5. Comparar el TXT generado contra el formato oficial esperado.
