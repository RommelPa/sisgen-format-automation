# Formato G7

El Formato G7 consolida información de compras, ventas, compromisos netos, transferencias de potencia y valorizaciones.

## Fuentes principales

```text
COMENE.DBF
VENENE.DBF
COMNET.DBF
TRAENE.DBF
VALENE.DBF
```

## Catálogo local

```text
config/local/g7_units.yaml
```

## Flujo soportado

```text
crear plantillas G7
validar plantillas G7
exportar DBF G7
validar fuentes G7
generar TXT G7
```

## Crear plantillas

```powershell
sisgen create-g7-templates `
  --period 2025-12 `
  --catalog config\local\g7_units.yaml
```

## Validar plantillas

```powershell
sisgen validate-g7-templates `
  --period 2025-12 `
  --catalog config\local\g7_units.yaml
```

## Exportar DBF

```powershell
sisgen export-g7-dbf `
  --period 2025-12 `
  --catalog config\local\g7_units.yaml
```

## Validar fuentes

```powershell
sisgen validate-g7-sources `
  --comene reports\dbf\2025-12\COMENE.DBF `
  --venene reports\dbf\2025-12\VENENE.DBF `
  --comnet reports\dbf\2025-12\COMNET.DBF `
  --traene reports\dbf\2025-12\TRAENE.DBF `
  --valene reports\dbf\2025-12\VALENE.DBF `
  --period 2025-12 `
  --catalog config\local\g7_units.yaml `
  --fail-on-errors
```

## Generar TXT

```powershell
sisgen create-g7-txt `
  --comene reports\dbf\2025-12\COMENE.DBF `
  --venene reports\dbf\2025-12\VENENE.DBF `
  --comnet reports\dbf\2025-12\COMNET.DBF `
  --traene reports\dbf\2025-12\TRAENE.DBF `
  --valene reports\dbf\2025-12\VALENE.DBF `
  --period 2025-12 `
  --catalog config\local\g7_units.yaml
```

## Revisión mínima

Antes de usar el TXT como entregable:

* validar que no existan errores
* revisar compras y ventas de energía
* revisar compromisos netos
* revisar transferencias de potencia
* revisar valorizaciones
