# Formato G1

El Formato G1 consolida información de generación y consumo propio.

## Fuentes principales

```text
CENHID.DBF
CENTER.DBF
DACOCE.DBF
COMCEN.DBF
```

## Catálogos locales

```text
config/local/cenhid_units.yaml
config/local/center_units.yaml
```

## Flujo soportado

```text
crear plantillas
validar plantillas
exportar DBF
validar fuentes G1
generar TXT G1
```

## Validar fuentes

```powershell
sisgen validate-g1-sources `
  --cenhid reports\dbf\2025-12\CENHID.DBF `
  --center reports\dbf\2025-12\CENTER.DBF `
  --dacoce reports\dbf\2025-12\DACOCE.DBF `
  --comcen reports\dbf\2025-12\COMCEN.DBF `
  --period 2025-12 `
  --cenhid-catalog config\local\cenhid_units.yaml `
  --center-catalog config\local\center_units.yaml `
  --fail-on-errors
```

## Generar TXT

```powershell
sisgen create-g1-txt `
  --cenhid reports\dbf\2025-12\CENHID.DBF `
  --center reports\dbf\2025-12\CENTER.DBF `
  --dacoce reports\dbf\2025-12\DACOCE.DBF `
  --comcen reports\dbf\2025-12\COMCEN.DBF `
  --period 2025-12 `
  --cenhid-catalog config\local\cenhid_units.yaml `
  --center-catalog config\local\center_units.yaml
```

## Revisión mínima

Antes de usar el TXT como entregable:

* validar que no existan errores
* revisar periodo
* revisar unidades esperadas
* revisar totales de generaci?n
* revisar consumo propio
