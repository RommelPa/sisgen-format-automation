# Formato G11

El Formato G11 reporta información hidroeléctrica y termoeléctrica.

## Fuentes principales

```text
CACEHI.DBF
CACETE.DBF
```

## Cat?logo local

```text
config/local/g11_units.yaml
```

## Flujo soportado

```text
crear plantillas G11
? validar plantillas G11
? exportar DBF G11
? validar fuentes G11
? generar TXT G11
```

## Crear plantillas

```powershell
sisgen create-g11-templates `
  --period 2025-12 `
  --catalog config\local\g11_units.yaml
```

## Validar plantillas

```powershell
sisgen validate-g11-templates `
  --period 2025-12 `
  --catalog config\local\g11_units.yaml
```

## Exportar DBF

```powershell
sisgen export-g11-dbf `
  --period 2025-12 `
  --catalog config\local\g11_units.yaml
```

## Validar fuentes

```powershell
sisgen validate-g11-sources `
  --cacehi reports\dbf\2025-12\CACEHI.DBF `
  --cacete reports\dbf\2025-12\CACETE.DBF `
  --period 2025-12 `
  --catalog config\local\g11_units.yaml `
  --fail-on-errors
```

## Generar TXT

```powershell
sisgen create-g11-txt `
  --cacehi reports\dbf\2025-12\CACEHI.DBF `
  --cacete reports\dbf\2025-12\CACETE.DBF `
  --period 2025-12 `
  --catalog config\local\g11_units.yaml
```

## Revisión mínima

Antes de usar el TXT como entregable:

* validar que no existan errores
* revisar información hidroeléctrica
* revisar información termoeléctrica
* revisar periodo y unidades
