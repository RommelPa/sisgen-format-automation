# Formato G8

El Formato G8 reporta venta y facturación de energóa eléctrica a clientes libres.

## Fuente principal

```text
VEFAME.DBF
```

## Catálogo local

```text
config/local/g8_clients.yaml
```

Este catálogo define los clientes libres válidos y sus códigos.

## Flujo soportado

```text
crear plantilla VEFAME
validar plantilla VEFAME
exportar VEFAME.DBF
validar fuentes G8
generar TXT G8
```

## Crear plantilla

```powershell
sisgen create-vefame-template `
  --source data\raw\VEFAME.DBF `
  --period 2025-12 `
  --catalog config\local\g8_clients.yaml
```

## Validar plantilla

```powershell
sisgen validate-vefame-template `
  reports\templates\VEFAME_2025_12_template.xlsx `
  --period 2025-12 `
  --catalog config\local\g8_clients.yaml `
  --fail-on-errors
```

## Exportar DBF

```powershell
sisgen export-vefame-dbf `
  --source data\raw\VEFAME.DBF `
  --template reports\templates\VEFAME_2025_12_template.xlsx `
  --period 2025-12 `
  --catalog config\local\g8_clients.yaml
```

## Validar fuentes

```powershell
sisgen validate-g8-sources `
  --vefame reports\dbf\2025-12\VEFAME.DBF `
  --period 2025-12 `
  --catalog config\local\g8_clients.yaml `
  --fail-on-errors
```

## Generar TXT

```powershell
sisgen create-g8-txt `
  --vefame reports\dbf\2025-12\VEFAME.DBF `
  --period 2025-12 `
  --catalog config\local\g8_clients.yaml
```

## Campos calculados

La plantilla VEFAME incluye campos calculados para evitar errores manuales.

```text
NENACTO = NENACHO + NENACFU
NFACPOT = NHRSPUN * 1000 * NPRPOHO + NFUHOPU * 1000 * NPRPOFU
NFACEXC = NEXHOPU * 1000 * NPRPOEX + NEXFUHO * 1000 * NPRPOEX
```

La generación del TXT G8 calcula también la facturación de potencia, exceso, energía activa, energía reactiva, otros, total y precio medio.

## Advertencia operativa

Los valores de prueba pueden generar totales absurdos si se usan precios o potencias ficticias.

Antes de usar el TXT como entregable, validar que:

* la energía total sea razonable
* la facturación total sea razonable
* el precio medio sea coherente
* los clientes correspondan al catálogo vigente
