# Formato U2

El Formato U2 reporta usuarios libres por clasificación CIIU.

## Fuente principal

```text
CIUGEN.DBF
```

## Catálogo local

```text
config/local/u2_ciiu.yaml
```

Este catálogo define la empresa, la ubicación y las clasificaciones CIIU activas.

## Campos principales

```text
CANOREG  Año SISGEN de dos dígitos
CMESREG  Mes
CCODGEN  Código de empresa
CCODREG  Código de región
CCODDEP  Código de departamento
CCODCIU  Código CIIU
CDESCIU  Descripción CIIU
NUSULIB  Número de usuarios libres
NCONLIB  Consumo de usuarios libres
NFACTOT  Facturación total
```

## Flujo soportado

```text
crear plantilla CIUGEN
-> validar plantilla CIUGEN
-> exportar CIUGEN.DBF
-> validar fuentes U2
-> generar TXT U2
```

## Crear plantilla

```powershell
sisgen create-ciugen-template `
  --source data\raw\CIUGEN.DBF `
  --period 2025-12 `
  --catalog config\local\u2_ciiu.yaml
```

## Validar plantilla

```powershell
sisgen validate-ciugen-template `
  reports\templates\CIUGEN_2025_12_template.xlsx `
  --period 2025-12 `
  --catalog config\local\u2_ciiu.yaml `
  --fail-on-errors
```

## Exportar DBF

```powershell
sisgen export-ciugen-dbf `
  --source data\raw\CIUGEN.DBF `
  --template reports\templates\CIUGEN_2025_12_template.xlsx `
  --period 2025-12 `
  --catalog config\local\u2_ciiu.yaml
```

## Validar fuentes

```powershell
sisgen validate-u2-sources `
  --ciugen reports\dbf\2025-12\CIUGEN.DBF `
  --period 2025-12 `
  --catalog config\local\u2_ciiu.yaml `
  --fail-on-errors
```

## Generar TXT

```powershell
sisgen create-u2-txt `
  --ciugen reports\dbf\2025-12\CIUGEN.DBF `
  --period 2025-12 `
  --catalog config\local\u2_ciiu.yaml
```

## Campos editables en plantilla

```text
NUSULIB
NCONLIB
NFACTOT
```

Los demás campos se generan desde el periodo configurado y el catálogo local.

## Reglas principales

* `NUSULIB` debe ser entero.
* `NUSULIB`, `NCONLIB` y `NFACTOT` no pueden ser negativos.
* El periodo no debe duplicarse en el DBF histórico.
* El código CIIU debe existir en el catálogo local.
* La descripción CIIU debe coincidir con el catálogo local.

## Revisión mínima

Antes de usar el TXT como entregable:

* validar que no existan errores
* revisar número total de clientes libres
* revisar consumo total
* revisar facturación total
* revisar que el orden de CIIU coincida con el catálogo vigente
